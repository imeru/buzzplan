# 회장 지도 이미지

학회가 공개한 회장 도면을 여기에 둔다. `data/<학회id>.json`의 `venue.maps[].image`가
`assets/maps/<파일명>` 형태로 이 폴더를 가리킨다.

- 파일명은 `<학회id>-<건물>-<층>.png`처럼 학회를 알아볼 수 있게 짓는다
- 원본 픽셀 크기를 그대로 쓴다. `width_px`와 `height_px`는 이 파일의 실제 크기여야 한다
- 핀 좌표도 원본 픽셀 기준이다. 이미지를 나중에 리사이즈하면 좌표가 전부 어긋난다
- 저작권 확인은 사람이 한다. 학회가 공개 배포한 도면만 커밋한다
- 핀 찍기와 축척 지정은 `map-editor.html`을 로컬 서버로 열어서 한다
